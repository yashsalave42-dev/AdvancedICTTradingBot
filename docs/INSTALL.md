# AdvancedICTTradingBot

## Purpose

This repository contains an MT5/MQL5 institutional-style trading framework built around deterministic Liquidity Sweep, MSS, and FVG logic with disciplined risk controls and transparent operational safety.

## Installation

1. Open MetaEditor.
2. Copy `MQL5/Include/AdvancedICT` to `MQL5/Include`.
3. Copy `MQL5/Experts/AdvancedICTTradingBot.mq5` to `MQL5/Experts`.
4. Compile the project.
5. Load on a demo account first.

## Quick start

- Configure risk thresholds in the EA inputs.
- Validate regime filters before enabling live execution.
- Use demo testing before any live deployment.

## Known limitations

- This is not a guaranteed-profit system.
- Execution quality depends on broker conditions, spread, and slippage.
- Historical performance and optimization must be independently validated.
